# ボートレース予想ツール

開催中の全場を1ページにまとめ、前日予想 → 展示後の直前予想へ自動で切り替えて表示します。

- 表示ページ: `docs/boatrace/index.html`（GitHub Pages では `/boatrace/`）
- データ作成: `boatrace/update.py`（GitHub Actions `.github/workflows/boatrace.yml` が定期実行）

## 表示内容

| 項目 | 内容 |
|---|---|
| 開催場 | 当日開催している全場だけを表示（1ページに全場、ページ上部のボタンで移動）。過去の日のデータは残さない |
| 予想 | 各艇の1着確率・印（◎○▲△）・3連単の買い目上位（確率・オッズ・期待値） |
| 前日 / 直前 | 展示前は「前日データ」。展示が出ると「展示反映」になり、前日予想と並べて表示 |
| 選手 | 当日の情報（進入・展示・スタ展・チルト・単勝オッズ）を大きく、過去の成績（全国・当地勝率、モーター、平均ST、F持ち、得意コース・得意場、直近10走）は選手ごとに小さく1行で表示 |
| 穴予想 | ◎○▲より下の艇から、人気（単勝オッズ）以上に力がある艇を「穴」として選び、その艇が1・2着に絡む高配当（20倍以上）の3連単を期待値の高い順に3点。オッズが出る前は外コースで一番強い艇を選ぶ |
| 展示 | 展示タイム、チルト、スタート展示の進入とST、天候・風・波 |
| オッズ | 単勝・3連単（締切60分前から取得）。単勝オッズは予想確率に4割混ぜる |
| 公式予想 | 公式サイトのコンピュータ予想が取れればレース情報に表示し、印を少し加点 |
| 成績 | 結果確定後に的中を表示し、その日の◎1着率・3連単的中率（前日 / 直前）を集計 |

## 非公開（パスワード）

予想データは公開ページに置くため、パスワードで暗号化しています（AES-256-GCM、鍵は PBKDF2-SHA256）。
ページを開くとパスワードを聞かれ、正しく入れるとその端末では次回から自動で表示されます（「ロック」で解除）。

1. GitHub のリポジトリ → Settings → Secrets and variables → Actions → New repository secret
2. 名前 `BOATRACE_PASSWORD`、値に好きなパスワードを入れて保存
3. このパスワードを知っている人だけが予想を見られます。変えたいときは同じ手順で値を更新すると、次の更新から新しいパスワードになります（このとき自前の結果記録は読めなくなるため作り直しになります）

`BOATRACE_PASSWORD` が未設定のまま GitHub Actions で動いた場合は、平文のデータを公開しないよう処理を中止します。
ページの見た目（HTML）とプログラムは公開のままですが、予想・オッズ・選手データは暗号化されていて読めません。
検索エンジンには載らないよう noindex も付けています。

## 更新のタイミング（日本時間）

- 7:20 当日の前日予想を作り直し（欠場などを反映）
- 18:10 / 21:40 翌日の前日予想（出走表と選手データ）
- 8:00〜21:59 10分ごと: 締切35分前〜締切のレースは直前情報（展示）、60分前からはオッズ、締切後は結果

展示が取れない・公式サイトに繋がらないときは、前日データの予想をそのまま表示します。

## 手元で動かす

```sh
pip install -r boatrace/requirements.txt
python -m boatrace.update prep --tomorrow   # 翌日の前日予想
python -m boatrace.update live              # 今日の展示・オッズ・結果を反映
# BOATRACE_PASSWORD=... を付けて実行すると暗号化して保存（付けなければ平文。手元で見るだけならそれで可）
python -m unittest boatrace.tests.test_boatrace
```

## 予想の考え方

コースの基本1着率（1コース55%…6コース2.5%）を土台に、全国勝率・級別・当地勝率との差・モーター2連率・
平均ST・F持ち・直近10走の平均着順・そのコースでの成績を加点減点。展示後は展示タイム（中央値との差）・
スタート展示のST・実際の進入コースを加え、強風（5m以上）や高波（8cm以上）のときは荒れやすい分だけ差を縮めます。
2・3着は Harville 式で計算し、3連単オッズとの積（期待値）が1.2以上の目は「妙味」として追加します。

## 注意

- 公式サイトの HTML 変更で一部項目が取れなくなることがあります。その場合は空欄（-）になり、取れた項目だけで予想します。
- 直近10走は公式の「直近3節成績」と、このツールが毎日貯める結果記録（`boatrace/state/history.json`）から作ります。
  運用を続けるほど、進入コースやSTつきの記録に置き換わります。
- 解説者・記者の予想は場ごとにサイトがばらばらで統一的に取れないため、公式のコンピュータ予想で代用しています。
