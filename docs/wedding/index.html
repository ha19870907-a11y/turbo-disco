💐 結婚式ムービー作成ツール

写真を並べるだけでムービーを作成します。BGMは動画ができた後から追加できます。

0. テンプレートを選ぶ

1. 写真・動画を追加

ここに写真・動画をドラッグ＆ドロップ
またはクリックして選択

複数選択できます。並び順はサムネイルをドラッグして入れ替えられます。（目安: 写真100枚以下推奨、動画1本200MBまで）
動画は「使用秒数」欄でムービー内で使う長さ（最大15秒）を調整できます。動画自体の音声は収録されません（BGMのみ収録）。
各サムネイルの下の欄にひとことキャプションを入れると、表示されている間だけ文字が重なって表示されます。

2. タイトル・演出設定

1. オープニング演出の設定

構成は「カウントダウン → 新郎パート → 新婦パート → 2人の思い出パート → クライマックス（お二人の名前発表）」の 順に自動で組み立てられます。実際の長さは各パートに追加する写真の枚数によって変わります （目安: 新郎・新婦パートは各15〜20枚、思い出パートは10〜15枚で合計約1分30秒〜2分）。
BGMは後の手順で追加できます。BPM120〜130前後のアップテンポな洋楽ロック/EDM系がおすすめです。

2. 写真・動画を追加（パートごと）

各パートに写真・動画をまとめて追加できます。動画は「使用秒数」欄でムービー内で使う長さ（最大15秒）を調整できます。動画自体の音声は収録されません（BGMのみ収録）。

3. ムービーを作成

ダウンロード（音声なし）

4. BGMを追加

先に音声なしムービーを作成すると、この欄が使えるようになります。動画と同じ長さで書き出し直します。複数曲を選ぶと選んだ順にクロスフェードしながら再生し、動画の長さに足りない分は自動で繰り返します（末尾はフェードアウトします）。

ここに音楽ファイルをドラッグ＆ドロップ（複数可）
またはクリックして選択

ダウンロード（BGM付き）

すべての処理はブラウザ内で完結し、写真や音楽が外部に送信されることはありません。
書き出しには Chrome または Edge の最新版を推奨します（対応形式: WebM）。動画の長さと同程度の生成時間がかかります。
