事業形態・地域・従業員数・売上規模などの条件から、 jGrants（国の補助金電子申請システム） に登録されている、現在利用できる可能性のある補助金・助成金や公的な支援制度を検索できます。

  • 「自分の会社で使える制度が分からない」
  • 「補助金を調べる時間がない」
  • 「どんな支援制度があるのか知りたい」

という方のための無料検索ツールです。個人事業主・フリーランス向けの制度も検索できます。

      補助金について専門家に相談したい方へ

      補助金・助成金の申請や、税務・労務・資金調達について専門家への相談を希望する方には、外部の相談サービスをご案内しています。 検索結果だけでは判断が難しい場合や、

      • 自社が対象になるか詳しく確認したい

      • 補助金以外の資金調達方法も検討したい

            こんな支援もあります

            補助金・助成金（応募・採択されるとお金がもらえる制度）が見つからない場合でも、融資・信用保証・ 経営相談・税制優遇など、jGrantsには基本的に掲載されない「支援制度」が使える場合があります。 金額・利率・要件は制度改定や指定期間によって変わるため、名称で検索し、必ず実施団体の公式サイト・ 最新情報で内容をご確認ください。

              データについて・ご注意

              • 検索対象データはjGrantsの公開APIから、 GitHub Actionsで1日1回サーバー側で取得し、このサイトに保存したものです（ブラウザからその都度APIを呼び出しているわけ ではないため、最新の公募開始・締切から反映まで最大1日程度のずれが生じることがあります）。
              • 複数の検索語でjGrants APIを検索してまとめているため、jGrantsに登録されている制度すべてを網羅しているわけではありません。 また、jGrantsには都道府県・市区町村が実施する補助金も一部登録されていますが、すべての自治体・商工会議所の制度を 網羅しているわけではありません。特にお住まいの市区町村や地域の商工会議所・商工会が独自に行っている制度は、 別途それぞれの公式サイトでの確認をおすすめします。
              • jGrantsは主に経済産業省・中小企業庁系の「補助金」を対象としており、厚生労働省系の「助成金」 （雇用調整助成金、キャリアアップ助成金など）は含まれません。
              • この検索結果は申請の可否を保証するものではありません。応募要件・締切・提出書類は必ず公式情報でご確認ください。
              • 掲載している情報は最新の情報と異なる場合があります。申請条件・募集期間・対象経費などは必ず公式情報をご確認ください。
              • 専門家への相談・紹介については、各サービス提供会社の条件が適用されます。当ツールが相談内容や結果を保証するものではありません（専門家紹介リンクには「広告」表示を付けています。詳しくは広告・アフィリエイトについて）。
              • 入力した情報はこの端末のブラウザ内にのみ保存され、外部には送信されません。専門家紹介のボタンをクリックした場合のみ、その先の紹介サービスのサイトへ移動します（クリックしただけで氏名・連絡先等が自動的に送信されることはありません）。
              • 当サイトは行政機関ではありません。掲載制度の申請代行や採択保証は行っておらず、公的機関等が公開する情報をもとにした民間の情報提供サービスです。詳しくはこのサイトについてをご覧ください。
